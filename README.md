## 🚀 Quick Start

### 1. Generating Award-Winning 3D Websites
Scaffold any of the 6 luxury 3D websites in 1 second:
```bash
# Scaffold a Mobile FinTech & Neobank 3D Showcase
node ultra-3d-web-experience/scripts/scaffold-3d.js --preset fintech --out ./my-fintech

# Scaffold a Sneaker Configurator
node ultra-3d-web-experience/scripts/scaffold-3d.js --preset sneakers --out ./my-sneakers
```
Available presets: `fintech`, `sneakers`, `agency`, `hair-beauty`, `tech`, `fashion`.

### 2. Using the Universal CLI (Vercel Labs Engine)
```bash
cd vercel-skills-cli
pnpm install
pnpm build
```

Install skills into any agent:
```bash
npx skills add vercel-labs/agent-skills
```

### 3. Exploring 2,690+ Skills Catalog
Browse the complete catalog in [`aas-core-skills/CATALOG.md`](./aas-core-skills/CATALOG.md) or query the local index:
```bash
cat aas-core-skills/skills_index.json
```

### 4. Using Production Document Engines (Anthropic)
Access the battle-tested document generation skills:
* **Word Documents**: [`anthropic-skills/skills/docx`](./anthropic-skills/skills/docx)
* **PDFs**: [`anthropic-skills/skills/pdf`](./anthropic-skills/skills/pdf)
* **PowerPoint Presentations**: [`anthropic-skills/skills/pptx`](./anthropic-skills/skills/pptx)
* **Spreadsheets**: [`anthropic-skills/skills/xlsx`](./anthropic-skills/skills/xlsx)

### 5. Injecting Modern UI/UX Guidelines
To empower your agent with senior frontend & UI design capabilities, point your agent to:
* [`ui-ux-pro-max/`](./ui-ux-pro-max)

## 🧠 Comment utiliser ce "Cerveau" d'Intelligence Design

Une fois ce dépôt publié sur GitHub (`https://github.com/seo-ben/skill-all.git`), **n'importe qui dans le monde peut utiliser ce "cerveau"** selon son profil et son environnement :

### 1. Utilisateurs d'Agents IA (Google Antigravity, Cursor, Claude Code, Windsurf, Codex)
Le dossier [`.agents/skills/`](./.agents/skills) respecte le standard universel des **AI Agent Skills**.

#### Comment l'installer :
* **Option A (Par projet)** : Cloner le dépôt ou copier le dossier `.agents/skills/` à la racine de votre projet :
  ```bash
  git clone https://github.com/seo-ben/skill-all.git
  cp -r skill-all/.agents/skills ./mon-projet/.agents/skills
  ```
* **Option B (Global pour toute votre machine)** : Déposer les skills dans la configuration globale de votre agent :
  * Pour **Antigravity / Gemini** : `~/.gemini/config/skills/`
  * Pour **Claude Code** : `~/.claude/skills/`

#### Ce qui s'exécute automatiquement :
Dès qu'un développeur donne une consigne à son IA (ex: *"Crée la landing page d'une application mobile de transfert d'argent"*), **l'IA lit ce cerveau et applique les règles d'élite sans qu'on ait besoin de tout lui dicter** :
1. **Moteur d'Intelligence Compétitive** : Recherche et benchmark automatique du top 1% mondial (Cash App, Linear, Apple, Dipa Inhouse).
2. **Éradication des anti-patterns débutants** :
   - Zéro carte carrée étouffante enveloppant des sections entières (toile blanche éditoriale libre).
   - Zéro formulaire desktop lourd pour présenter une application mobile.
   - Zéro badge pillule redondant au-dessus des titres.
   - Zéro zéro barré de code (`0̸`) sur les montants financiers (`font-variant-numeric: tabular-nums lining-nums`).
   - Zéro lien de navbar à rallonge (termes uniques et percutants).
3. **Pods architecturaux & Profondeur multi-planaire** :
   - Cadrage en stade ovale continu (`border-radius: 130px / 85px`) et dôme cintré avec reflets spéculaires de verre.
   - Séparation en profondeur $Z$ (orbites à $Z: -35\text{px}$, hardware à $Z: +25\text{px}$, badges flottants à $Z: +75\text{px}$ à $+95\text{px}$).
4. **Scrollytelling 3D vectoriel & Micro-éléments vivants** :
   - Entrées aérodynamiques en piqué et démasquage textuel progressif (`clipPath`).
   - Faisceau laser scanner QR en temps réel et ondes radar sonar.
   - Animations GSAP 100% bidirectionnelles scrubbées (haut et bas).

### 2. Développeurs sans IA (Scaffolding instantané via CLI)
N'importe quel développeur peut générer un projet prêt pour la production en une seule commande :

```bash
# 1. Cloner le dépôt
git clone https://github.com/seo-ben/skill-all.git
cd skill-all

# 2. Générer le site avec le preset fintech (ou sneakers, agency, tech, hair-beauty, fashion)
node ultra-3d-web-experience/scripts/scaffold-3d.js --preset fintech --out ./mon-site-client

# 3. Lancer et tester en local
cd ./mon-site-client
npx serve .
```
Le projet généré contient directement le fichier `index.html` complet, les 11 visuels HD dans `assets/`, et la configuration Three.js + GSAP.

---

### 3. Distribution universelle en 1 ligne via Vercel Skills (`npx skills`)
Le dépôt intègre le moteur [`vercel-skills-cli/`](./vercel-skills-cli). Les développeurs peuvent installer une compétence directement dans leur projet sans cloner manuellement le monorepo :

```bash
# Installer le moteur 3D spatial
npx skills add seo-ben/skill-all --skill ultra-3d-web-experience

# Installer le designer d'impact UI/UX
npx skills add seo-ben/skill-all --skill bencium-controlled-ux-designer
```
